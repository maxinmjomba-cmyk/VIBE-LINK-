# VibeLink 🔥

**VibeLink** is a modern, creator-first social platform where people share videos,
chat in real time, and connect through real vibes.

---

## ✨ Features
- 🎬 Upload & share short videos
- 💬 Real-time chat & messaging
- 🔔 Notifications (messages & follows)
- ➕ Easy follow system
- 🚩 Report & block users
- ⚙️ Settings & Privacy Policy
- 🛡️ Basic admin moderation panel
